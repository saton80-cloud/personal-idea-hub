# 安卓录音、转写与签名

## 录音和同步

- 安卓手机可在首次离线使用时录音。录音保存在应用私有目录的 `voice/*.m4a`，待处理记录保存在本机 SQLite；此时不要求连接服务器。
- 手机有互联网且在设置中配置了可用的 Whisper 兼容转写地址和 API Key 后，会在打开今日工作时尝试转换待处理录音，也可以点“联网转为文字”。转写请求从手机直接发向配置的 HTTPS 服务，和局域网服务器无关。
- 用户可以修改识别文字；点击“加入今天”后，文字成为任务详情，原录音仍保存在本机。进入同一局域网并完成登录或扫码配对后，任务通过原同步机制上传，录音另行上传至服务器。PC 在今日工作中点任务旁的“录音”可从服务器获取并打开。
- 服务器录音目录默认 `/var/lib/personal-work-board/voice`，可用 `Voice__DataDirectory` 配置。MySQL `voice_notes` 表记录任务和录音的关联；升级时现有数据库会新增该表。每日备份同时打包录音目录。
- 转写服务的 API Key 存在手机系统安全存储，服务器不会接收 API Key。录音会发送到用户配置的第三方服务，费用和网络可达性取决于该服务。DeepSeek 的文本模型接口不能直接代替语音转写接口。

## APK 验签及安装排查

- CI 只保留单个 `PersonalWorkBoard-Android-0.4.0-Signed.apk`，使用 Android SDK `apksigner verify --verbose --print-certs` 检查，并输出 SHA-256。不可安装旧的无 `-Signed` 后缀 APK。
- 正式升级必须用与旧版本**相同的发布证书**签名；若已安装了不同证书但相同包名的旧版，系统会拒绝覆盖。先备份应用数据和同步，再决定是否卸载旧版。卸载会删除本地离线录音和未同步任务。
- `apksigner` 通过只能证明 APK 签名结构有效，不能替代 nova10 的实机安装。若仍提示“证书不通过”，需要保留 APK 文件名、SHA-256、安装界面截图，以及电脑连接手机执行 `adb install -r 文件.apk` 的原始错误代码，定位应用签名不一致、文件损坏或华为安装器拦截。
- CI 环境中生成的签名若与已安装版发布证书不同，需再用固定发布证书签名后交付。严禁把密钥和口令一起提交到公开 GitHub 仓库。
