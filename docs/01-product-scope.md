# 产品范围

## 定位

“个人工作看板”是单人使用的工作、创意和项目推进系统，不设计企业多用户审批流程。

## 管理对象

代码项目、网站、新产品、产品创意、日常工作和普通点子使用同一条主流程，但可按类型筛选。

## 核心闭环

1. 快速记录到工作收件箱。
2. 明确优先级、目标时间和下一步行动。
3. 转为项目或今日任务。
4. 记录进度、阻塞和投入时间。
5. 新想法作为子创意进入当前优化、后续版本或独立项目分支。
6. 阶段验收形成通过、有条件通过或返工结论。
7. 所有设备同步到同一MySQL权威数据。

## 本版本不做

- AI分析中心及DeepSeek接入
- 多人、部门、角色和审批
- 公网云同步
- 自动向GitHub写业务文档
- 浏览器Web客户端

AI与GitHub业务文档同步接口可以在后续版本重新评估，但不能影响V0.2同步基础。
