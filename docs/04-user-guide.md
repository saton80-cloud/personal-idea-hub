# PC与Android使用手册

## Windows首次登录

1. 打开“个人工作看板”。
2. 输入服务器地址，例如`http://192.168.1.100`。
3. 输入安装服务器时设置的管理员用户名和密码。
4. 登录后进入今日工作页。

## 连接Android

1. PC进入“同步中心”。
2. 点击“生成5分钟配对二维码”。
3. Android打开应用，选择“扫描PC端二维码配对”。
4. 授予相机权限并扫描。
5. 手机自动进入工作台并进行第一次全量同步。

二维码只能用一次；失败或过期后在PC重新生成。

## 离线工作

离开局域网后仍可新建和编辑内容，记录先保存到本机SQLite。回到局域网后进入同步中心点击“立即双向同步”，后续版本将增加前后台自动触发。

## 数据冲突

同步中心显示未解决冲突数量时，不代表数据丢失。双方版本均已保留；在冲突处理功能完成前，不要反复编辑同一冲突记录。

## 每日提醒

设置页可调整上午计划和晚间复盘时间。V0.2.0在应用打开时提醒；系统后台通知列入下一阶段。
