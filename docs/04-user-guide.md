# PC、Android与HarmonyOS使用手册

## Windows首次登录

1. 打开“个人工作看板”。
2. 输入服务器地址，例如`http://192.168.1.100`。
3. 输入安装服务器时设置的管理员用户名和密码。
4. 登录后进入今日工作页。

## 连接Android

1. PC进入“同步中心”。
2. 点击“生成5分钟配对二维码”。
3. Android打开应用，选择“扫描PC端二维码配对”。
4. 授予相机权限并扫描。
5. 手机自动进入工作台并进行第一次全量同步。

二维码只能用一次；失败或过期后在PC重新生成。

## 连接HarmonyOS 7

1. 确认手机系统为HarmonyOS 7（已按`7.0.0.107`适配），并与PC、Rocky Linux服务器连接同一局域网。
2. 打开鸿蒙版“个人工作看板”，点击“扫一扫配对”。
3. 扫描PC同步中心生成的5分钟一次性二维码。系统扫码页不可用时，可复制完整`pwb://pair?...`内容并使用粘贴配对。
4. 配对成功后手机直接连接服务器并进行首次增量同步；PC无需一直开机。

鸿蒙版使用原生ArkTS/ArkUI实现，不安装Android APK。HAP的签名与安装方法见[HarmonyOS 7构建与安装](09-harmonyos7-build-install.md)。

## 离线工作

离开局域网后仍可新建工作项目和今日任务。Windows/Android先保存到本机SQLite，HarmonyOS先保存到应用私有Preferences。回到局域网后进入同步中心即可触发增量同步；系统级前后台定时同步列入下一阶段。

## 今日任务

1. 在“今日工作”页填写任务标题。
2. 选择优先级并填写预计分钟数。
3. 点击“加入今天”。任务会先保存到本机，连接局域网服务器后上传。
4. 上午计划和晚间复盘时间可在设置页调整。

## 数据冲突

同步中心显示未解决冲突数量时，不代表数据丢失。双方版本均已保留；在冲突处理功能完成前，不要反复编辑同一冲突记录。

## 每日提醒

设置页可调整上午计划和晚间复盘时间。V0.3.0在应用打开时提醒；HarmonyOS和MAUI的系统后台通知列入下一阶段。
